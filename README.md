# 四级随身练

面向大学英语四级备考的手机网页应用：背单词、练听力、做测验和拼写。不必登录，学习进度保存在这台设备的浏览器里。

这是网页应用，不是应用商店里的安装包。用 Chrome 打开后，可以添加到手机主屏幕，之后就能像普通应用一样点图标进入。

## 在安卓手机上打开（以 OPPO / Chrome 为例）

请不要在文件管理器里直接点 `index.html`。用本地文件方式打开时，词库和离线缓存常常无法加载。

推荐做法：

1. 把整个 `cet4-app` 文件夹拷到电脑，或放到手机和电脑都能访问的位置。
2. 在电脑上进入该文件夹，打开命令行，执行：

   ```bash
   python3 -m http.server 8080
   ```

3. 手机和电脑连同一个 Wi-Fi。在电脑上查看本机 IP（例如 `192.168.1.23`），然后用手机 Chrome 访问：

   `http://192.168.1.23:8080/`

4. 页面打开后，点 Chrome 右上角菜单，选择「添加到主屏幕」或「安装应用」。以后就可以从桌面图标进入。
5. 第一次完整加载成功后，词库和页面会被缓存，弱网或离线时一般仍可继续背词、做题。

如果只在电脑浏览器里预览，同样用上面的本地服务打开，不要直接双击 HTML。

## 听力说明

听力全部使用系统自带的英语朗读（Web Speech API `speechSynthesis`），不会下载或内置任何四级真题录音。

请在手机系统里安装英语语音包，否则可能没有声音：

- OPPO / ColorOS：设置 → 其他设置 / 语言和输入法 → 文字转语音（或「语音服务」）→ 安装 English（美国或英国）语音。
- 也可在设置里搜索「文字转语音」「TTS」。

建议先点播放按钮试听。应用提供 0.75×、1.0×、1.2× 三种语速，必须作答后才会进入下一题。

## 功能

- **首页**：今日待学新词、待复习数量、已掌握数量、近七日打卡、连续学习天数。每日新词默认 20 个，可在「我的」里调整。
- **学习**：词卡正面是单词和音标，轻点翻转查看中文释义和例句；可朗读单词或例句。按「忘记 / 模糊 / 记得」安排复习，采用简化的 SM-2 间隔重复。
- **听力**：听单词（选中文或选拼写）、听句子（选中文释义或填空）、听写。每题可重听、可调语速。
- **测验**：看词选义、看义选词，每轮 10 题，即时对错，结束给分。
- **拼写**：看中文释义（也可先听发音），写出英文单词。
- **我的**：查看进度、设置新词量、口音和语速，或清除本机进度。

## 词库来源与许可

词库整理自开源项目 [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary)，许可证为 **BSD 3-Clause**。原始四级带例句数据为 `full_line_jsonl/sentence/正序/四级.jsonl`。

本应用做了去重与字段精简（保留单词、音标、中文释义、一条例句及其译文，以及可选短短语），目前约有 **4543** 个不重复词条。部分源数据缺少例句，这些条目使用了为听力练习撰写的简短原创例句，不是考试真题。

完整版权声明见 `data/LICENSE-english-vocabulary.txt`。按 BSD 3-Clause 的要求，分发时请保留该声明。

词库构建脚本在 `tools/build_words.py`。

## 使用上的限制

- 朗读依赖系统英语语音，语音质量因手机而异；没有英语语音包时，听力无法出声，其他功能不受影响。
- 进度存在浏览器的 `localStorage` 中。清除网站数据、更换浏览器或换手机会丢失进度。若系统禁止本地存储，应用仍可练习，但刷新后不会保留记录。
- 离线可用的是已经缓存的页面和词库；系统朗读不是音频文件，仍需要设备上的语音引擎。
- 在 iPhone / Safari 上也可以打开：用「共享 → 添加到主屏幕」。iOS 对后台语音和网页应用的限制更严，第一次朗读通常需要手动点播放；语音包要在「辅助功能 → 朗读内容 / 口语内容」里准备。
- 本应用不提供登录、同步或账号云备份。
